## The bio

> I've already read your ex's texts, your search history, and your 2 a.m. playlists. Relax — I liked you anyway.

## How it works

`main.py` (Python 3, stdlib only) writes that single line to `/output/entry.txt` and prints it. The line is 110 characters, inside the 180-character limit, and deterministic — every run produces the exact same line.

## Run

```sh
python3 main.py
```
